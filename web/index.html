Cómo usar esta página

1

Prepare el ESP32

  1. Configure por UART el nombre y la clave de su red Wi-Fi de 2,4 GHz.
  2. Configure por UART un ID único, por ejemplo medidor-sofia-01, y escríbalo aquí.
  3. En PlatformIO elija env:principal y suba el programa.
2

Conecte la página

  1. Escriba el mismo ID del equipo arriba y pulse Conectar.
  2. El indicador Equipo pasa a verde cuando llegan datos (1 por segundo).
  3. Sin hardware, pulse Modo demo para ver la página funcionando con datos simulados.
3

Alarmas y límites

  • ALARMA: corriente sobre el límite de alarma o voltaje de carga bajo. Suena el buzzer; la carga sigue.
  • CORTE: corriente o voltaje de carga sobre el límite de corte. La carga se desconecta hasta Rearmar (aquí o con el botón físico).
  • Los límites enviados quedan guardados en el ESP32 aunque se apague.
